## 真实时间试玩

使用 Chrome 实时渲染和普通游戏操作驱动，未注入资源、HP、人口或时间。该过程是自动化浏览器试玩，不称为人工手动试玩。

1. 首轮 1801.161 秒现实时间、1801.05 秒模拟时间。完成六项引导与主要建设，18 次模型请求已返回，零浏览器错误。湿地返巢因 A* 首段网格连接切过树干而卡住，因此首轮没有通关。
2. 修复路径网格连接、整段树干碰撞检测和路点切换后，导入首轮真实存档，继续普通操作 695.929 秒。完成四项进化、加固与两位守卫留守，海上来客离岛后完成 180 秒安居。
3. 累计约 **41 分 37 秒** 实时试玩，在累计模拟时间 2497 秒达成 `first-island-73429-49940`。续玩 7 次真实模型请求全部返回，无请求失败或浏览器错误。

首轮有一条模型提案的证据 ID 不合法，被契约拒绝并由规则接续；这不是一次模型请求失败，也没有越过引擎执行。模型请求配置为 `doubao-seed-2.0-pro`，此次实际返回模型为 `doubao-seed-2-1-turbo-260628`，二者分别记录。

## 发现并修复的问题

- 树边卡路：A* 以前只检查网格点，首段连接和提前切换路点会切入圆形树干。现在整段检查并保留起点连接，使用实际湿地坐标回归。
- 同页重载误报另一页面占用：重载复用本标签页身份，同时保留新标签页 fencing 和旧写入拒绝。
- 公网浏览器后台计时被限制时，本页租约可能先到期；现在只有 owner 或 fencing token 已改变才判为接管。相同身份在原子事务内续租；真实接管后仍拒绝旧页续租和写入。
- HTTP 来源没有 `crypto.randomUUID` / `subtle`：使用安全随机数 UUID 和经验证的 SHA-256 实现回退，仍校验存档和请求。
- 两次投喂过近时动作提前取消：角色会等待当前食物享用完再完成投喂，扣费仍仅一次。
- 预留口粮导致虚假的满仓提示：入库提示排除口粮，取粮和归还不增加采集/入库任务进度。
- 涨潮浅滩困住非游泳个体：沿不比当前脚下更深的路径实际退回高地，无瞬移。
- 系统造成的考验中断：加固费用只退一次；满仓部分作为待入库材料保留，不能把中断算胜利。无路返海的生物保留显示并继续寻找归路。
- 发布候选的 Node 24.20.0 / SQLite 3.53.4 在该服务器挂载目录报写入错误，而普通文件可写。已用同一目录验证 Node 24.15.0 / SQLite 3.51.3 的 WAL、建表和插入成功并固定镜像；候选失败回滚也已实际触发，旧站继续服务。
