# 03 · 两栖物种与海上来客

状态：拟实施规格。两种新物种均为原创设定；数值是首轮测试基线。

## 1. 两种来客

| 项目 | 潮背螈 `tideback` | 砾牙滩蜥 `reefjaw` |
| --- | --- | --- |
| 形象 | 扁宽身体、圆吻、背部潮纹、桨状尾、短粗四肢 | 狭长身体、低伏步态、砾石色背甲、齿吻、侧扁长尾 |
| 生态角色 | 中性、结伴迁徙的沿岸杂食生物 | 会争夺沿岸食物、受挫后撤退的机会性捕食者 |
| 现有类型映射 | `grazer`，扩展可投喂/海陆运动特征 | `predator`，扩展好奇/争食/撤退特征 |
| 生命 | 70 | 58 |
| 陆地 / 海中移动速度 | 1.6 / 2.6 单位每秒 | 2.6 / 3.4 单位每秒 |
| 攻击 | 正常不主动攻击；近距离受伤后优先逃离 | 6 点基础伤害，1.2 秒冷却，无毒、无穿甲 |
| 队伍 | 2–4 只 | 普通来客 2–3 只，首次考验固定 2 只 |
| 喜好 | 小雨后、退潮觅食，风雨时寻找背风岸 | 傍晚、食物吸引的岸段，受守卫阻挡会试探后离开 |
| 撤退 | 受到伤害、食物耗尽或行程结束 | 任一个体 HP ≤35%，或队伍损失至少 1 只，整队转撤离 |
| 岛内停留 | 90–180 秒 | 60–150 秒，考验窗口另按章节规则 |

这些动物不是天然阵营。砾牙滩蜥也可以被食物引导，潮背螈受到捕猎后也会避开该岸。`kind=predator` 不等于看见玩家就必须无限追杀；攻击仍需真实感知、距离和当前行为允许。

## 2. 活动空间

### 2.1 空间分层

1. **陆地与内陆湿地**：沿用原有地形、树干障碍和栖息地。
2. **潮间带**：按慢变水位计算浅水/干滩，可随潮位改变可走区域。
3. **近岸通道**：连接外海与有效登陆点，不使用现有岛缘限制阻断游泳物种。
4. **外海航路**：以岛外半径约 52–58 的合法水面点形成有限航路图；不扩大为无限海洋地图。

现有水面在画面上远大于岛屿，但当前 `walkable()` 会拒绝岛缘外移动，因此“已有游泳”不能直接证明“能够从外海登陆”。必须新增明确的海路导航。

海上实体首版仍限制在 `abs(x), abs(z) <= 60` 的世界包围范围，实际外海控制点半径不超过 58。坐标只是关卡编译器的生成范围，不是可以硬编码后不验收的最终登陆点。

### 2.2 航路与登陆点生成

新增拟定模块 `src/core/sea-navigation.js`，按地形离线预检或初始化预编译生成 4 组候选岸段：西岸湿地入口、北侧背风岸、东岸岩滩、南侧缓岸。最终点位由实际地形检验决定。

每条 `SeaRoute` 包含：外海入口、2–4 个中间水面点、近岸点、登陆过渡点、岸上集合点、返海候选；附允许物种、潮位桶、天气集合及是否开放敌对来客。

必须验证：

- 所有海段连续采样均为足够水深，不能穿过陆地；陆段使用现有树障碍与可走性。
- 首尾共享过渡点，游泳到涉水再到行走连续；高度由统一 `waterPose` 计算。
- 至少两个岸段在三种潮位桶中保持可用于考验的撤离路线。
- 玩家无需侧鳍也能在可走陆地观察、引导或抵御考验队伍；最终集合点不能只存在于深水。
- 所有普通和考验敌对路线都不穿过巢心 8 单位保护圈；登陆点距离巢穴至少 18。
- 第一次海上预警后至少还有 60 秒模拟时间才能上岸。海路很短时通过远海等待补足，不能靠把生物瞬间减速到近乎不动伪装行程。

海路图服务于海上迁移；陆上局部移动继续用 A*。不让所有普通小芽和同伴自动获得无限远海游泳能力。

## 3. 队伍生命周期

```text
available_opportunity
  → reserved
  → announced
  → offshore_wait / approaching
  → landing
  → onshore
  → departing
  → resolved
```

异常分支：`reserved/announced → cancelled`；`approaching/landing → rerouting → departing`；全部成员死亡则 `resolved(defeated)`。被玩家统治的成员转换控制权，从迁移队伍移除；所有成员都转移时 `resolved(adopted)`。

| 状态 | 规则 |
| --- | --- |
| 机会 | 引擎提供合法物种、队伍模板和路线，Agent 可接受、等待或放弃 |
| 保留 | 预留个体和危险额度；尚不创建任何玩家可攻击实体 |
| 预警 | 创建可见的预警事件和地图岸段标记；发布预计靠岸时间 |
| 海上出现 | 按冻结的成员名单一次创建实体；玩家能看见水纹、背脊和行进 |
| 靠近/登陆 | 逐段校验水深与通道；切换 swim/wade/land 姿态，保留原成员 ID |
| 岸上活动 | 觅食、观察、交流、争食、自卫；不直接增减巢穴仓库 |
| 离开 | 每只仍活跃成员实际返回海路出口；可被观察到离岛 |
| 结束 | 冻结成员去向、玩家行为、收支与事件；释放仍占用的配额 |

`arrivalId` 和成员 ID 在保留阶段由引擎生成，重复网络消息不会再次创建。生成数量只能由队伍模板和规则随机流决定，模型不能填 `spawn_count`。

### 3.1 通道阻塞与撤离

潮位桶变化后重新检查尚未经过的段落；可用则继续，不可用则选已预检备用岸段。无法安全登陆时沿海路返回，记录取消，不能把来客搬到巢边。

已上岸者等待最近可用出海点，并处于非追击状态。若连续 30 秒没有位移进展，先执行局部脱困；随后允许进入离岛消隐，仅当离开玩家视野、无战斗、无近距离互动且已经走到合法岸边时使用。若这些条件不满足，继续显示并等待路线修复，考验记为可恢复的中断，不能用悄悄删除敌人判玩家获胜。

## 4. 配额、节奏与新手保护

| 配额 | 初始值 | 结算方式 |
| --- | --- | --- |
| 岛内常住野生个体 | 初始 16、上限 24 | 原有常住补员机制受上限约束 |
| 活跃来客队伍 | 最多 2 | `reserved` 起占用，`resolved/cancelled` 释放 |
| 活跃来客个体 | 最多 8 | 保留名额与已创建成员一起计算，不双计 |
| 敌对登陆/岸上个体 | 最多 3 | 敌对 approaching 开始占用，返海且脱离威胁后释放 |
| 每游戏日普通来客 | 最多 2 支，其中敌对最多 1 支 | 按模拟日账本限额，不因重载重置 |
| 族群总成员上限 | 保持容量系统，现有上限可达 18 | 海上被统治动物不算族群人口 |
| 全部非玩家实体 | 硬上限 64 | 常住、同伴、被统治动物、来客均计入；尸体清理也需有界 |

新手保护：前 600 秒以及 6 项引导尚未完成时，都不产生普通敌对登陆；和平潮背螈可在 t≥360 后出现。巢心 8 单位不开放敌对进入，保护圈外 8–12 为警戒区，不在其中创建来客。

引导完成后，普通敌对来客仍需有 60 秒预警。一次导致玩家倒下的敌对来客结束后，至少 180 秒不再出现新的敌对队伍；压力不会因等待模型而积累成集中爆发。

考验预订一支固定两只砾牙滩蜥队伍，**占用同一份队伍、个体和敌对配额**，并替代该日的普通敌对名额。若额度已占满，先等待普通队伍实际离开，界面明确显示“岸边尚有来客”。考验期间不再生成普通敌对事件。

## 5. 玩家互动

### 5.1 观察与投喂

保持单击看信息、双击捕猎、长按互动的输入方式。首次海上来客提供一次简短说明，不阻断移动。

新增“投喂”近距离操作：玩家与目标距离不超过 3，2.5 秒动作完成时从**玩家背包**扣 8 食物；不足则不执行、不扣款。界面直接显示“背包需 8 食物”。同一队伍普通投喂冷却 15 秒，记录群体信任与食物消耗，不能无成本刷关系。

投喂产生真实食物引导事件和短时和平状态 90 秒；饱食来客更倾向撤离或跟随食物轨迹。普通投喂不自动完成潮汐考验，考验所需有效投喂次数和禁止伤害窗口见 [05](05-first-island-victory.md)。

新增配套“携带口粮”：小芽在巢边 5 单位内，仓库至少 8 食物、背包空位至少 8 且没有未用完的预留口粮时，可把 8 食物从仓库转入背包并标记为 `reservedFood`。这是转移，不是资源生成，不计采集、入库或任务奖励。提供“归还口粮”操作，按仓库余量转回，满仓剩余仍留在背包。

`deposit()` 自动入库时只存放非预留食物与材料，避免刚取出的口粮在下一 tick 被自动送回。投喂优先消耗预留部分；玩家倒下后背包按原规则损失，预留量也同步裁剪到剩余食物之内。`reservedFood` 必须保存和校验为 `0 <= reservedFood <= carry.food`。

基础背包容量只有 12，不能同时装两次投喂所需的 16 食物。共存路线允许分两次准备：投喂一次后沿安全岸返回取粮，或在岸边继续采集；扩容进化只是便利。考验地图必须验证“登陆点→巢区取粮→返回”一趟在 40 秒模拟时间内可走完，确保 90 秒和平期足够第二次投喂，不能隐性强制扩容。

### 5.2 交流、统治与放归

现有冠饰交流、冠饰 + 双角 + 任意专精的统治前置继续生效；新物种要使用自身最大生命核对 40% 条件。交流增加个体亲近，投喂增加群体遭遇记录，两者不能混作同一数值。

被统治动物保留物种、海陆运动能力和个体 ID，移除野生控制权；不增加族群人口或育幼容量。首版最多同时拥有 4 只海上来源的追随者，达到上限时明确提示先放归；现有旧档常住追随者不被迁移强制删除。

放归时若在内陆，沿路前往合法海岸；若在深水，则就近选择外海路线。严禁恢复旧的已结算 `arrivalId` 从而重复掉落、通关或奖励。

### 5.3 驱离与争食

砾牙滩蜥会先接近沿岸食物和可见猎物，保护圈外可发生战斗。玩家可以召唤守卫抵御，造成足够伤害触发整队撤退。群体开始撤离后停止主动追击，仍可对继续攻击它的玩家作短暂自卫。

首版没有建筑耐久和任意偷取仓库功能。来客只实际消耗野外食物，或在范围内攻击实体。若未来增加偷食/损坏设施，需独立定义到场动作、损失上限、修复和账本，不能靠 Agent 文本实现。

## 6. 死亡、重生与经济守恒

原有野生 `hurt()` 会写入 `respawnAt = time + 150`。这不能直接套在海上来客身上：

- 常住野生动物保持当前 150 秒恢复周期作为首版基础，恢复点仍要验证地形和群体归属，不借此无限扩张。
- 海上来客使用 `origin: marine`；被击败后进入该队伍的永久终结成员记录，不在原地或海上定时复活。
- 每个来客成员最多产生一次战利品，绑定 `memberId` 和 `lootEventId`；沿用现有击败奖励作为初始基线，是否缩减需通过收益测试决定。
- 队伍结束后，未来新来客使用新的成员 ID 和日配额；不能反复加载同一场景重新收取奖励。
- 食物节点、玩家背包、族群仓库、投喂和战利品分别记账；Agent 输出不直接增加任何一类资源。

## 7. 模型、动画、声音和界面

新增可编辑 Blender 源对象和 `tideback.glb`、`reefjaw.glb`；沿用现有模型生成脚本和资产清单规范，但需要两种不同体态，不能只给原物种换色。

动画至少包含陆地四足步态、涉水、摆尾游泳、上岸过渡、取食、警戒、受击、返海。运动涟漪继续使用同一水面时间；远海使用少量背脊与水纹，进入近岸后呈现完整形体。两个新增模型必须覆盖加载、阴影、碰撞占位、信息卡与见闻图鉴。

海岸预警使用岸段方向和水纹图标，例如“西岸出现了几道靠近的水纹”，看见队伍后才显示物种名称。地图区分“已发现来客”和“未识别动静”，不把未见过的准确全队坐标直接暴露给玩家。

普通出场和离场事件各只通知一次，同一队伍状态变化不连续刷屏。手机布局以现有紧凑卡片为基线，保留停止互动和地面撤退的操作空间。
